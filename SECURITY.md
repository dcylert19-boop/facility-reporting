# Security Policy

Please report vulnerabilities privately using GitHub's **Report a vulnerability** feature for this repository. Do not open a public issue with exploit details. Include affected versions, reproduction steps, impact, and a suggested mitigation if known. The maintainer will acknowledge reports and coordinate disclosure and fixes.

Supported versions are the current `main` branch until formal releases exist. Never commit credentials or production data. The local `.env.example` and Compose credentials are development-only examples.
